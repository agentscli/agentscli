Codex has a `/plan` command (and `Shift+Tab` cycles the collaboration mode) that switches the session to Plan mode. For a hard guarantee that nothing is written, combine permission primitives instead:

```bash
codex --sandbox read-only --ask-for-approval on-request
```

- **`--sandbox read-only`** - the agent physically cannot write files or run mutating commands.
- **`--ask-for-approval on-request`** - anything that needs escalation prompts you.

Switching out of this posture mid-session: `/permissions` opens an interactive picker with presets like **Read Only** and **Auto** that applies the change to the running session. Restarting with new flags is the alternative.
