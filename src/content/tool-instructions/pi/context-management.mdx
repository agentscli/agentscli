**Sessions are tree-structured**, not linear. Every branch point (e.g. rewinding and trying a different approach) is preserved rather than discarded — `/tree` navigates between branches, and the whole tree lives in a single session file.

**Compaction** runs automatically near the context limit, and you can trigger it yourself with `/compact` (optional custom instructions after the command). Compaction behavior is also customizable via extensions if you want different summarization than the default.

**Steering mid-run:** press **Enter** to send a steering message while Pi is still working — it's folded in without waiting for the current turn to finish. **Alt+Enter** queues a follow-up message for after the current run completes, if you don't want to interrupt.

**Carrying context out:** `/export` writes the session out; `/share` produces a shareable link.
