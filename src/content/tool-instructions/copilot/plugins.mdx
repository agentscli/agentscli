Copilot has the densest plugin/marketplace surface of any CLI in foundations scope, but one of its two historical surfaces is gone. Read the deprecation first, because most third-party writing about Copilot extensibility predates it.

**Copilot Extensions (GitHub App-based) - retired.** These were the `@`-invocable Chat extensions distributed through GitHub Marketplace, in two flavors (**Skillsets** for retrieval, **Agents** for full LLM-backed responses). GitHub [blocked new extension creation on 2025-09-24 and disabled the feature entirely on 2025-11-10](https://github.blog/changelog/2025-09-24-deprecate-github-copilot-extensions-github-apps/), replacing it with MCP on the reasoning that an MCP server is built once and works across assistants instead of being rebuilt per platform. If you are porting one, MCP is the migration target. Note the scope of the sunset: it covers the *server-side, GitHub-App* extensions only. Client-side VS Code chat participant extensions are unaffected and still supported.

**Copilot plugins** - the live bundle surface (enterprise-managed plugins are still called out as public preview; the plugin format itself ships in product docs):
- Bundle agents + skills + hooks + MCP server configs + LSP configs into one installable unit
- Format shared between **VS Code agent plugins** and Copilot CLI plugins
- Distributed via **plugin marketplaces** - Copilot ships with two default marketplaces registered: [`github/copilot-plugins`](https://github.com/github/copilot-plugins) (official) and [`github/awesome-copilot`](https://github.com/github/awesome-copilot) (community, 48+ plugins)
- Marketplaces can be hosted on github.com, any Git server, or a local filesystem
- Enterprise admins can configure baseline plugins available to every user

**MCP Registry** ([github.com/mcp](https://github.com/mcp)) - curated, one-click MCP server install from inside the IDE. Separate from the plugin marketplace; MCP servers are a component plugins can ship, not a replacement for them.

**`awesome-copilot`** is the practical jump-off: real-world instructions, prompts, skills, agents, hooks, and plugins published by GitHub and the community.

Note the terminology overload, which the deprecation has made worse rather than better: "extension" can still mean the retired GitHub-App Extensions, a client-side VS Code chat participant extension, or just a VS Code extension. **Plugins** (marketplace-registered, bundle-of-everything) are a separate primitive from all three.
