Copilot CLI ships a native **Subagents** primitive: the main agent can run built-in or custom agents in a separate context window and receive a result back. Availability and invocation differ between Copilot CLI, VS Code, and hosted agents, so do not transfer a CLI example to another surface without checking its docs. *As of 2026-08-07.*

**Any custom agent doubles as a subagent.** A **custom agent** (`.agent.md`, discovered at `.github/agents/`, or the Claude-compatible `.claude/agents/`) is dual-purpose: pick it from the chat agents dropdown to switch personas, or let another agent delegate to it via `runSubagent` - same file, two invocation paths. Relevant frontmatter:

```yaml
---
name: security-reviewer
description: Reviews a change for security regressions.
tools: ['read', 'search']
mcp-servers: []
---
```

**Invocation is agent-initiated, not typed by you** - the coordinating agent decides isolation helps and calls `runSubagent` on its own; natural-language hints ("investigate X in isolation," "run these in parallel") are enough to nudge it. This is a different invocation model from Claude Code's `Agent` tool, which a user can also trigger by name.

**Parallel and nested execution:** subagents can run side by side. The supported profile fields and nesting behavior are surface- and version-specific; use the current GitHub schema rather than copying frontmatter from another agent product. *As of 2026-08-07.*

Legacy **Copilot Extensions** (`@extension-name` in Chat) were separate, full external agents running on an extension provider's servers, not isolated sub-contexts of your local session. GitHub's server-side, GitHub-App-based extension surface was retired in late 2025, so examples such as `@docker` and `@sentry` should not be presented as a current GitHub Marketplace integration.

**Copilot Coding Agent** (cloud, GitHub Actions-backed) is also separate from the in-session primitive above - an async hand-off that returns a PR, not a subagent inside your current session. Reach for it when the isolation needs to outlive the session, not just a subroutine within it.
