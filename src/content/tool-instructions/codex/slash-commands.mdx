**Built-in slash commands:** `/model`, `/review`, `/permissions`, `/diff`, `/mcp`, `/skills`, `/plan`, `/compact`, `/fork`, and others. Codex also lets you **queue** input (including a slash command) with Tab while a turn is running - it fires once the current turn finishes.

**Custom prompts are gone.** The `~/.codex/prompts/` files and the `/prompts:<name>` namespace were deprecated and then removed in Codex 0.117.0 (a maintainer states "removed completely starting in 0.117.0" in openai/codex issue 15941). Reusable prompts now live in **skills**.

**Skills** are invokable via `/skills` to browse or `$<skill-name>` to invoke directly. A skill is more structured than a plain prompt file. No argument-substitution placeholders (`$1`, `$ARGUMENTS`) are documented for skills; the text you type after the name reaches the model as part of the message.
