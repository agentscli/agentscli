**No separate `hooks.json`.** Pi folds hooks into its **extension** system: TypeScript modules subscribe to lifecycle events through the ExtensionAPI (`pi.on(...)`) and can also register tools, commands, and UI.

**Where extensions live:**
- `~/.pi/agent/extensions/` — global (always loaded)
- `.pi/extensions/` — project (trust-gated; see [Configuration](/foundations/configuration/))

**Hot reload:** `/reload` picks up extension edits without restarting the session.

**Verified event families** (from current ExtensionAPI docs — not exhaustive):

- `project_trust` — before project-local resources load; a handler can own the trust decision
- `session_start` / `session_shutdown` — session lifecycle (startup, resume, fork, switch)
- `tool_call` — before a tool runs; can **block** (the enforcement point for permission gates)
- `session_before_compact` / `session_compact` — compaction hooks
- Turn/agent/message events (`turn_start`, `agent_end`, `message_end`, …) for observation

The stock example is a **permission-gate** extension that intercepts `bash` on `tool_call` and confirms before dangerous patterns run — hand-rolling the approval prompt Pi doesn't ship by default (see [Permissions](/foundations/permissions/)).
