**Models:** OpenAI GPT models. The Codex docs currently recommend GPT-6.1 Sol (`gpt-6.1-sol`) when your account has it, with `gpt-6-luna` for focused repeatable tasks and `gpt-6-astra` for the most complex work. Older IDs retire on a schedule (`gpt-5.4` on ChatGPT sign-in ended 2026-08-31), so re-check before pinning one.

**Switching:** `/model` mid-session or `--model <id>` at launch. A `model` field in `config.toml` (or in a profile - see [Configuration](/foundations/configuration/)) sets the default.

Codex is built around OpenAI models. A custom provider or gateway works only if it exposes a Responses API-compatible endpoint; `wire_api = "chat"` and Chat Completions-only endpoints are no longer supported.

**Default model and roster:** these vary by client, authentication method, account, and release. Codex doesn't publish one static catalog for every surface - use the model picker or run `codex debug models` (experimental) to print the model catalog Codex sees, then pin an ID only when you control that environment.
