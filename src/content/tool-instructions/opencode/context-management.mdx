**OpenCode V2, compact (manual).** Run `/compact` in the TUI to summarise on demand. The exact aliases, keybinds, and server endpoints vary by release; check the [current V2 compaction reference](https://opencode.ai/v2/docs/compaction) before scripting them. *As of 2026-08-07.*

**Compact (automatic).** OpenCode V2 detects when a conversation is approaching the model's context limit, makes a summarisation call, and replaces detailed history with a concise summary. Its V2 configuration uses `buffer` and `keep.tokens`; older configuration references use different names and defaults, so label examples with the version you run.

The summary follows a fixed structured template - **objective, important details, completed and active work, blockers, next moves, and relevant files** - so you don't steer it with per-call instructions the way you do in some other tools; the structure is the contract. Generation runs on the session's own model with tools disabled and a 4096-token ceiling, and the newest slice of raw context is kept alongside the summary rather than replaced by it (`keep.tokens`, 8000 by default).

**Turn it off - partly.** Setting `auto` to `false` switches off the preflight size check, not compaction itself: manual `/compact` still works, and OpenCode still compacts once to recover from a provider context-overflow error. A second overflow after that recovery is returned as an error rather than compacted away.

```json
// opencode.json
{ "compaction": { "auto": false } }
```

**Carry across.** Resume from the CLI with `opencode --continue` / `-c` (most recent session) or `opencode --session <id>` / `-s` (a specific one); add `--fork` to branch instead of continue. In the TUI, `/sessions` (aliases `/resume`, `/continue`) picks one, and `/new` (alias `/clear`) starts fresh. `opencode session` manages sessions from the shell, and `/share` creates a link to the current conversation. `/undo` and `/redo` step changes back and forth.

**Plugin option.** A community **Dynamic Context Pruning** plugin adds configurable pruning thresholds for finer control over when context is shed. *Verify TUI slash-command names and config keys against the current OpenCode docs - these have moved between releases.*
