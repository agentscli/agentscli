This is the final chapter of the [GitHub Copilot course](/course/copilot/); if you landed here from a search, the [course overview](/course/copilot/) is the start path. Every chapter before this one introduced a single capability in isolation, on the slice of work that needed it. Roles in their own chapter. Permissions in theirs. [The cloud agent](/course/copilot/automation/) - the one that works on GitHub while you do something else - in its own. That is the right way to *learn* the moves - one at a time, named, with the reasoning made explicit. It is not how a day works. A real day hands you a shared-library bug before standup and a feature request after lunch, and you make all the calls - which surface to use (completions or chat), which [role](/course/copilot/modes/) to run, what [permission level](/course/copilot/permissions/), how much reasoning - without announcing them.

This chapter is what that looks like when the moves have gone quiet.
