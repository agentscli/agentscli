VS Code is where this course has been first-class, and that was deliberate: it has the fullest set of agent features for Copilot. But "first-class" was never "only." The honest question to close on is the one a teammate asks the first week: *I live in a JetBrains IDE - how much of this do I lose?*

The answer is reassuring, and worth stating up front. **Almost nothing you actually built is tied to VS Code.** The conventions you wrote in the [Rules chapter](/course/copilot/rules/) - the `AGENTS.md`, the `CLAUDE.md` - are repo-shaped, not editor-shaped, and JetBrains reads the same files. The [skills](/course/copilot/skills/) you packaged follow the cross-tool [Agent Skills format](https://docs.github.com/en/copilot/concepts/agents/about-agent-skills), and your [MCP servers](/course/copilot/extending/) and [custom agents](/course/copilot/custom-agents/) carry their own support story there. What you steered the agent to do carries; only some of the agent features are still maturing outside VS Code, and this chapter is about knowing which.
