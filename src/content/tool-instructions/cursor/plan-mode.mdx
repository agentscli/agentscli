Cursor made **Plan Mode** a first-class mode, separate from Agent - not just a permission flag. It is activated from the mode picker or by pressing `Shift+Tab` in the chat input (the CLI also has `/plan`, `--plan`, and `--mode=plan`); Cursor may also suggest it for complex tasks. *As of 2026-10.*

**What Plan Mode does:**

1. Agent asks clarifying questions.
2. Researches the codebase for context (read-only at this stage).
3. Generates a comprehensive implementation plan as an **editable markdown file**.
4. Plans are saved in your home directory by default; use "Save to workspace" to move one into the repo for sharing.
5. User edits the plan inline (add/remove todos, change approach) before clicking to build.

Cursor documents **plan-with-one-model, build-with-another** as a way to pair a reasoning model for planning with a faster execution model for the build step. Plans can be branched and compared where the installed surface supports those controls. *As of 2026-08-07.*

Cursor documents Plan Mode as a research-and-plan workflow, but does not publish an exhaustive tool allowlist. Treat its read-only behavior as a workflow expectation, not as a security guarantee.
