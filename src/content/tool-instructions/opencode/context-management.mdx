**Compact (manual).** Run `/compact` (alias `/summarize`) in the TUI to summarise on demand. Keybind: `<leader>c`.

**Compact (automatic).** On the OpenCode 1.x line (npm `opencode-ai`, latest 1.19.4 as of 2026-10), a hidden `compaction` agent summarises the conversation when it approaches the model's context limit and replaces the older history with that summary. You steer it with three `opencode.json` keys:

```json
// opencode.json
{ "compaction": { "auto": true, "prune": false, "reserved": 10000 } }
```

- `auto` - compact automatically when context is full (default `true`).
- `prune` - also drop old tool outputs to save tokens (default `false`).
- `reserved` - token buffer left free so compaction itself doesn't overflow the window.

Setting `auto` to `false` stops the automatic preflight, not compaction itself: manual `/compact` still works.

**Version note.** OpenCode 2 is a separate opt-in line (installed via `opencode.ai/v2/install` or `@opencode/cli`, docs at `opencode.ai/v2/docs`) and names these settings differently (`buffer`, `keep.tokens`). Label any example with the version you run.

**Carry across.** Resume from the CLI with `opencode --continue` / `-c` (most recent session) or `opencode --session <id>` / `-s` (a specific one); add `--fork` to branch instead of continue. In the TUI, `/sessions` (aliases `/resume`, `/continue`) picks one, and `/new` (alias `/clear`) starts fresh. `opencode session` manages sessions from the shell. `/undo` and `/redo` step changes back and forth. `opencode export` and `opencode import` move a session as a file.

**Sharing is discontinued.** Session sharing was shut down in v1.19.1 (2026-10-15): `/share` now fails with "Session sharing has been discontinued", `/unshare` only clears the local link, and `run --share` is deprecated. The public docs pages still describe it; use `opencode export` to hand a session to someone.

**Plugin option.** A community **Dynamic Context Pruning** plugin adds configurable pruning thresholds for finer control over when context is shed. *Verify TUI slash-command names and config keys against the current OpenCode docs - these have moved between releases.*
