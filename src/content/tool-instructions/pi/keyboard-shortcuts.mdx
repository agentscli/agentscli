**Re-checked October 2026 against Pi's keybindings documentation (1.4.0).** Run `/hotkeys` for the bindings active in your session. Despite being the most minimal harness in this set, Pi ships a full keymap - roughly a third of it inherited readline editing, the rest its own.

**`Esc` cancels the current agent turn.** In dialogs and selectors it closes or backs out instead.

**Clipboard keys behave unusually here, more so than in any other tool:**

- `Ctrl+C` copies the selection if one exists; otherwise it clears the editor, and a second press exits. It does not send SIGINT.
- `Ctrl+V` pastes files (macOS), images, or text from the clipboard.
- `Ctrl+X` copies the last assistant message (or the selected message in `/tree`). It does not cut.

**`Ctrl+R` renames a session in the session picker** (`/resume`), a different job from the reverse history search it does in a shell. `/name` renames the current session directly.

**Line editing is readline-style:** `Ctrl+A`/`Ctrl+E`, `Ctrl+B`/`Ctrl+F`, `Ctrl+W`, `Ctrl+K`, `Ctrl+U`, `Ctrl+Y`, with `Alt+B`/`Alt+F`/`Alt+D` for word operations. `Ctrl+Z` suspends the process to the shell (not on native Windows); undo is `Ctrl+-`.

**Useful ones:** `Ctrl+G` opens the current input in `$VISUAL` or `$EDITOR`. `Ctrl+L` opens the model selector and `Ctrl+P` cycles through the models in scope (`/scoped-models`). `Shift+Tab` cycles the thinking level, and `Ctrl+O` / `Ctrl+T` expand tool output and thinking blocks. `Shift+Enter` and `Ctrl+J` insert a newline.

**Rebinding:** `~/.pi/agent/keybindings.json` maps keys onto namespaced action ids (`tui.editor.*`, `tui.altScreen.*`, `app.*`), and every default is remappable. Run `/reload` after editing it.

**Prompt history:** `Up` / `Down` browse older and newer prompts when the cursor is at the top or bottom of the buffer; dedicated `tui.editor.historyPrevious` / `historyNext` actions exist but are unbound by default. **Fullscreen mode** (the default as of 1.0) adds transcript bindings such as `PageUp` / `PageDown` to scroll, `Ctrl+Up` / `Ctrl+Down` to jump between prompts, and `Ctrl+Shift+F` to search the transcript. There is no reverse-incremental history search.
