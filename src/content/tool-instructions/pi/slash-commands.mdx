Type `/` for command completion in the TUI. A few built-ins: `/model` (switch model), `/compact` (manual context compaction), `/tree` (navigate session branches), `/export`, `/share`, `/reload` (hot-reload extensions).

**Skills** are invoked the same way - `/skill:name` - but are a distinct primitive from commands (see [Skills](/foundations/skills/)); the `/skill:` prefix is how the slash surface disambiguates the two.

**Prompt templates** are the closest thing to Claude Code's custom commands: drop a markdown file in a `prompts/` resource path and it expands via `/templatename`. These are manual-invocation only - the model can't call a prompt template itself the way it can decide to load a skill.

**Extensions can register their own commands** through the ExtensionAPI, so the command surface grows with whatever extensions you've installed and trusted for the project.
