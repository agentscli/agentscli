title: "The CLI's own slash commands"
description: "The interactive TUI carries a built-in set of slash commands for modes, model, context, and control - a different list from the editor's picker."
---

The interactive TUI has its own set of **built-in slash commands** - and this is a different list from the `/` picker in the editor. In the editor, `/` opens a picker over your subagents, skills, and custom commands. In the CLI, `/` runs commands that control the session itself. The reference lists about three dozen of them (as of September 2026 - [slash-command reference](https://cursor.com/docs/cli/reference/slash-commands)); this page groups the ones you'll lean on, with the reference's own wording where it is short:

- **Modes** - `/plan [prompt]`, `/ask`, and `/debug [prompt]` switch the session's posture: the same Agent, Ask, Plan, and Debug surface as the editor's mode picker, driven from the terminal (Agent is the default posture; the reference documents switches to the other three, not back).
- **Model and spend** - `/model [filter]` selects a model; `/max-mode` toggles Max Mode on legacy request-based plans (the reference's own description; Max Mode is the legacy-plan context expansion, per the [Max Mode documentation](https://cursor.com/docs/context/max-mode), not a feature of current usage-based plans).
- **Context and session** - `/summarize` summarizes the conversation to reduce context (`/compress` is an alias); `/clear` starts a new chat session (`/new`, `/new-chat`, and `/newchat` are all aliases of it, so a tutorial that lists `/new-chat` as a separate command is listing an alias); `/resume` opens recent chats and resumes one; `/rewind` jumps back to a previous message; `/fork` forks the current chat into a new session.
- **Control surfaces** - `/run-everything [on|off|status]` toggles Run Everything - the run mode where "every tool call runs automatically", per the [run modes documentation](https://cursor.com/docs/agent/security/run-modes) - or shows its status (`/auto-run` is an alias); `/sandbox` configures sandbox mode and network access; `/mcp [list|list-tools] [identifier]` manages MCP servers (Cursor's mechanism for plugging in external tools) and lists their tools; `/plugin` manages plugins and marketplaces.
- **Housekeeping** - `/help [command]` shows help or one command's details; `/config` configures CLI settings interactively; `/update` updates the CLI, `/logs` shows the debug log path, `/about` prints version, system, and account info, and `/quit` exits.

The set is version-sensitive in both directions: new commands arrive flagged as rolling out (`/goal` was, at the time of writing), names move, and aliases collect. Type `/` in your installed CLI or read the reference before you lean on a command your muscle memory brought over from the editor.

Two boundaries keep this page honest. First, these commands configure an *interactive* session; they are not a substitute for a sandbox, a disposable runner, or least-privilege credentials. A headless `-p` run should use documented flags and an explicit output format instead - the containment is the environment, not the command set. Second, these exist only in the interactive TUI: a headless run isn't a session you type `/` into, it's a single shot. The slash commands are for when you're sitting in the terminal agent driving it live.

Which is the point at which the interactive surface runs out and the automated one takes over. Put the single-shot command on a runner and `budgetcli` (the course's illustrative personal-finance API) gets a reviewer that never forgets to show up.
