GitHub's [Copilot hooks reference](https://docs.github.com/en/copilot/reference/hooks-reference) documents hooks for Copilot CLI and cloud agent. VS Code has a separate **Agent hooks (preview)** surface with compatible naming - treat it as preview, not as the same stable surface as CLI/cloud.

**The events you'll reach for first** (GitHub's reference documents 14 events, including `agentStop`, `errorOccurred`, `permissionRequest`, `preCompact`, `subagentStart`, `subagentStop`, and `userPromptTransformed`):

- `sessionStart` - agent session begins or resumes
- `sessionEnd` - session completes or is terminated
- `userPromptSubmitted` - every user prompt
- `preToolUse` - fires before any tool call; can **approve or deny** the call (the deterministic gate)
- `postToolUse` - fires after a tool call returns, the reactive counterpart to `preToolUse`

**Surfaces that support hooks today:**

- **VS Code** - Agent hooks in **preview** (mid-2026)
- **Copilot CLI** - file-based hooks
- **Copilot cloud agent** ("cloud agent hooks") - configured per-repo
- **Copilot SDK** - programmatic hooks for extension authors

**`preToolUse` is the powerful one** where supported: it runs an external command before any tool invocation, receives the tool call payload, and decides allow, deny, or ask (`ask` becomes deny in the cloud agent and CLI autopilot) - the policy-enforcement primitive. Command hooks are fail-closed on a crash or non-zero exit; timeouts fail open.

**`copilot-setup-steps.yml` is *not* a hook.** It's a dedicated GitHub Actions workflow at `.github/workflows/copilot-setup-steps.yml` that runs **once per cloud agent task** before the agent starts, to install dependencies and prep the sandbox. Use it for environment prep on the cloud agent surface only - it doesn't gate runtime tool calls and doesn't apply to VS Code Chat.
