Every command on this page was read out of the installed binary (`claude --help`, v2.1.234) or the official docs - not from another cheat sheet. That distinction matters: the popular community sheets circulating GitHub list flags like `--production-mode`, `--cache-results`, and `--security-enabled` that **do not exist**, and mark `--max-turns` as a favorite without noting it vanished from `--help` output in 2.1.x (it still works - print mode only - and is marked `docs` where it appears below).
