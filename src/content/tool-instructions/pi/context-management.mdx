**Sessions are tree-structured**, not linear. Every branch point (e.g. rewinding and trying a different approach) is preserved rather than discarded - `/tree` navigates between branches, and the whole tree lives in a single session file.

Keep `/tree` distinct from resuming. `/tree` moves you around *inside* the session you're already in; it is not a picker for past sessions. For that, `/resume` opens an interactive picker mid-session, and `pi -r` does the same at startup. `/fork` and `/clone` are separate commands again, for splitting a session off rather than navigating within one.

**Compaction** runs automatically near the context limit - specifically once used tokens exceed the context window minus a reserve, 16384 tokens by default - and you can trigger it yourself with `/compact`, with optional custom instructions after the command. That inline steering is native; you don't need an extension for it. Extensions come in when you want to change the summarisation itself, via the `session_before_compact` event.

**Steering mid-run:** press **Enter** to send a steering message while Pi is still working. It's delivered once the in-flight tool-call turn completes rather than interrupting mid-call. **Alt+Enter** queues a follow-up for after the entire run finishes.

**Carrying context out:** `/export` writes the session out as HTML; `/share` uploads it as a private GitHub gist and gives you an HTML link.
