**Chat built-ins (VS Code, JetBrains, web):**

- `/explain` - explain selected code or context
- `/fix` - propose a fix for errors or selection
- `/tests` - generate tests
- `/new` - scaffold a new project or file
- `/doc` - generate documentation
- `/optimize` - suggest performance improvements
- `/help` - list available commands
- `/clear` - clear chat history
- `/init` - generate a starter `.github/copilot-instructions.md`
- `/create-prompt` - generate a reusable prompt file

**Prompt files** are Copilot's custom-command primitive: `.github/prompts/*.prompt.md`. Configurable location via `chat.promptFilesLocations`. Invoked as `/<prompt-name>` from chat. Support frontmatter (mode, tools, description) and can reference instructions files. This is the closest analog to Claude Code's user-defined slash commands.

**Chat participants (`@`-mentions, VS Code):** `@workspace`, `@vscode`, `@terminal`, `@github`, plus `@<extension-name>` for any installed client-side VS Code chat participant extension. The exact participant set is surface/version-dependent; `@` attaches context and `/` runs an action. The *other* `@`-invocable surface - GitHub-App-based Copilot Extensions from the Marketplace - was disabled on 2025-11-10 in favour of MCP, so `@`-mentions you find in older writing may point at something that no longer exists.

**Other surfaces (non-IDE).** The `copilot` CLI has its own slash set (`/login`, `/model`, `/context`, `/compact`, `/experimental`, `/lsp`, `/feedback`), The older `gh copilot` GitHub-CLI extension (`gh copilot suggest`, `gh copilot explain`) was a separate tool, not Chat slash commands - and it was retired on 25 October 2025.
