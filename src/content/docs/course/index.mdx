These are **hands-on courses**, not reference. Each one picks a single agent, hands you a real project, and walks you through a week of work with it - every lesson is a problem you'll actually hit and the exact move that fixes it. The techniques are the same discipline taught spec-first in [Foundations](/foundations/); the courses are where you build the muscle memory.

Pick the tool you work in. The spines are the same teach-by-doing arc, so once you've done one, the next is mostly learning where that tool puts things.
